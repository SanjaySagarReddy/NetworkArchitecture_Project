BHTTP/1 Server

Binary HTTP over TCP Server (bserve/1.0)

Status: Online

Welcome to bserve, the server implementation of the BHTTP/1 protocol.

  • Fixed 12-byte binary frame headers
  • HBP header block compression with static dictionary table
  • Chunked DATA frame streaming (max 16 KiB chunks)
  • Strict path containment and sequential request handling
